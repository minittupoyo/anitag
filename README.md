# anitag

Tauri v2 と React / TypeScript で構築されたアニメ動画ファイルのリネームおよびメタデータ管理ツールです。

## 機能

- **ファイルスキャンと解析**
  - 指定ディレクトリ内の動画ファイルからシーズン番号・話数をパース
  - 修正版表記（`v2`, `v3` 等）や画質・コーデック等のノイズ自動除去に対応
- **Annict API 連携**
  - Annict からアニメ作品タイトルおよび各話サブタイトルを取得
- **プレビューと比較**
  - 実行前に変更前後のファイル名、変更状態（実行可能 / スキップ / 重複衝突）を一覧表示
- **履歴とUndo**
  - 直前のリネーム処理を元のファイル名に一括復元
- **フォーマットプリセット**
  - `{work_title}`, `{ep_num:02d}`, `{ep_num}`, `{ep_title}`, `{season:02d}`, `{season}`, `{ext}` などの変数タグを用いたフォーマットの作成・保存

## アクセストークンの設定

Annict API から情報を取得するためのアクセストークン設定方法：

1. ヘッダーの `API Token` ボタンをクリック
2. 個人用アクセストークンを入力して保存

一度保存すると次回起動時も自動的に適用されます。環境変数 `ANNICT_TOKEN` が設定されている場合は、そちらも参照されます。

## 開発とビルド

### 開発モードの起動
```bash
npm install
npx tauri dev
```

### ビルド
```bash
npm run build
npx tauri build
```
